1. Game Overview

1.1 Elevator Pitch

Boba Dash is a bubble tea time management game where players brew, serve, and decorate their way to a thriving boba empire. With 1000+ drink combinations, 108 levels, social features like Taste Test and Cover Shift, and 100% ad-free gameplay, Boba Dash delivers a pure, satisfying experience for casual gamers worldwide.

1.3 Core Differentiators

🧋 Modular Drink System

5 Bases × 14 Flavors × 8 Toppings × 5 Cup Types = 2,800 possible combinations. Fisher-Yates seeded shuffle generates 1000 unique drinks with consistent results across devices.

📱 Offline-First Architecture

Single-player game fully playable offline. Social features activate when online. HybridStorage: AsyncStorage first, Supabase async sync.

🤝 Asynchronous Social

Taste Test (visit friends' shops) + Cover Shift (help with delivery overflow) + Leaderboard (3 categories) + Custom Recipes (player-created signature drinks).

🎨 Pure Cosmetic Monetization

Zero ads, zero pay-to-win. All 18 SKUs are purely cosmetic: decorations, recipe slots, ingredient skins, avatar items, and theme music.

2. Core Gameplay Loop

2.1 Primary Loop (per level)

Start Level → Customers arrive → Read order → Brew drink (Base → Flavor → Topping → Cup) → Serve → Earn coins → Delivery orders (dual-thread tension) → Combo chain → Day complete → Spend coins (shop/decorate) → Next level

2.2 Dual-Thread Tension

Each level features two simultaneous streams of demand:

ThreadDescriptionTension Source
Walk-in CustomersCustomers queue at the counter with patience timersPatience runs out → customer leaves → lose coins
Delivery OrdersPhone rings with delivery orders, each with a countdownTimer expires → order fails → lose coins + combo resets

The player must constantly decide: serve the waiting customer, or grab the delivery before it times out? This dual-thread tension is the core of Boba Dash's gameplay.

2.3 Combo System

ComboMultiplierCondition
x11.0xNormal serve
x21.2x2 consecutive perfect serves
x31.5x3 consecutive perfect serves
x52.0x5 consecutive perfect serves
x103.0x10 consecutive — "On Fire!" status

Combo resets on: failed serve, expired delivery, or wrong ingredient. Perfect serve = correct drink served before patience drops below 50%.

2.4 Ingredient Inventory

Players manage a limited inventory of ingredients. Running out of an ingredient mid-level forces the player to adapt their menu or lose customers. Ingredients can be restocked between levels using coins earned.

3. Drink System

3.1 Modular Composition

Every drink is composed of 4 modules, each chosen independently:

ModuleOptionsCount
Base TeaBlack Tea, Green Tea, Oolong Tea, Jasmine Tea, Thai Tea5
FlavorStrawberry, Mango, Matcha, Taro, Brown Sugar, Honey, Lavender, Peach, Passion Fruit, Chocolate, Mint, Rose, Coffee, Vanilla14
ToppingTapioca Pearls, Coconut Jelly, Grass Jelly, Pudding, Crystal Boba, Aloe Vera, Cheese Foam, Whipped Cream8
Cup TypeClassic Cup, Mason Jar, Tumbler, Bubble Cup, Cone Cup5

Total possible combinations: 5 × 14 × 8 × 5 = 2,800

3.2 Fisher-Yates Seeded Shuffle

The game generates 1000 unique drinks using a Fisher-Yates shuffle with a fixed seed, ensuring:

  • Consistency: Same 1000 drinks on every device — no random different drinks per player
  • Fairness: No duplicates, every drink is unique
  • Deterministic: Drink #500 is always the same drink, enabling social features (friends can reference specific drinks)

3.3 Drink Pricing

Price is calculated based on module combination:

basePrice + flavorPrice + toppingPrice + cupPrice + levelMultiplier

Example: Black Tea (5) + Matcha (8) + Tapioca Pearls (6) + Mason Jar (4) × Level 3 multiplier (1.3) = 29.9 ≈ 30 coins

5. Social System

5.1 Overview

Boba Dash features 4 social mechanisms built on asynchronous interaction — players don't need to be online simultaneously. Social features use Supabase Edge Functions with native platform integration (Apple Game Center + Google Play Games).

🧋 Taste Test

Visit a friend's shop and taste a free boba. Both players earn coins!

Revenue split: Taster 35% / Shop Owner 20% / System Subsidy 45%

Limit: 5 taste tests/day, 1 per friend/day

🤝 Cover Shift

Help a friend handle delivery overflow when they're offline. Process their pending deliveries and split earnings.

Revenue split: Helper 15% / Shop Owner 70% / System Subsidy 15%

Limit: 5 cover shifts/day

🏆 Leaderboard

Compete with friends in 3 categories, reset weekly (Monday 00:00 UTC):

  • Weekly Income
  • Max Combo
  • Decoration Score

Dual-mode: native Game Center/Play Games UI + Supabase cross-platform fallback

📝 Custom Recipes

Create your signature drink: Base → Flavor → Topping → Cup → Name it!

30% chance a Taste Test serves a friend's custom recipe.

2 recipe slots (1 free + 1 unlockable at $0.99)

5.2 Friend System

FeatureDetail
Friend Slots5 free, fixed (no paid expansion)
Add Friend6-digit invite code or native platform friends (Game Center / Play Games)
Deep Linkboba-dash://invite?code=ABC123
Tier System5 tiers based on total income — prevents cross-tier arbitrage in Taste Test

5.3 Anti-Abuse Mechanisms

  • Daily limits per action type (5 taste tests, 5 cover shifts)
  • 1 action per friend per day
  • Server-side atomic operations (PostgreSQL FOR UPDATE + transactions)
  • Tier-based earning calculation (prevents high-tier players farming low-tier friends)
  • Profanity filter on custom recipe names and shop names

  • RevenueCat: Unified IAP management across Apple App Store + Google Play

7.4 Offline-First Design

HybridStorage Class: AsyncStorage is the primary storage layer. Supabase syncs in the background when online. If offline, the game runs fully on local data. Conflict resolution: cloud wins if divergence > 20%.

# Boba Dash — 产品规格书

## 产品定位

Boba Dash 是一款面向全球市场的 Bubble Tea 时间管理烹饪游戏。玩家经营自己的 boba 店，制作饮品、装饰店铺、与好友社交互动。

## 目标用户

- 主要：休闲玩家，女性 18-35，喜欢烹饪/餐厅类游戏
- 次要：Bubble tea / boba 爱好者，全年龄

## MVP 功能清单

- [x] 1000种饮品生成（Fisher-Yates 洗牌）
- [x] 108关关卡（4关教学 + 104关程序化）
- [x] 核心制作循环（Glass → Base → Flavor → Blend → Topping → Serve）
- [x] 顾客系统（耐心条、VIP、急躁顾客）
- [x] 外卖系统（双线程张力）
- [ ] 社交系统（Taste Test / Cover Shift / Leaderboard / Custom Recipes）
- [ ] 变现系统（5轨 18 SKU）
- [ ] 头像定制系统
- [ ] 店铺音乐系统

## 核心差异点

1. 双线程外卖张力机制
2. 1000种程序化生成配方
3. 异步社交机制（Taste Test / Cover Shift）
4. 零广告纯内购
5. 头像 + 音乐定制

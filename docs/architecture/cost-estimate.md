## 1. 基础设施成本

### 1.1 Supabase

| 项目 | Free Tier | Pro Tier ($25/月) |
|------|-----------|-------------------|
| 数据库容量 | 500 MB | 8 GB |
| 带宽 | 5 GB/月 | 50 GB/月 |
| MAU (Monthly Active Users) | 50,000 | 100,000 |
| Edge Function 调用 | 500,000/月 | 2,000,000/月 |
| Edge Function 执行时间 | 50 ms wall-clock | 400 ms wall-clock |
| 数据库连接 (direct) | 15 | 30 + PgBouncer |
| 存储 | 1 GB | 100 GB |
| 每日自动备份 | 无 | 7天 |
| API 请求速率 | 无限制(Custom) | 无限制 |

**Boba Dash 使用量估算**：

| 指标 | 每DAU/日 | 1K DAU | 10K DAU | 100K DAU |
|------|---------|--------|---------|----------|
| Edge Function 调用 | ~8次 | 240K/月 | 2.4M/月 | 24M/月 |
| 数据库读操作 | ~50次 | 1.5M/月 | 15M/月 | 150M/月 |
| 数据库写操作 | ~10次 | 300K/月 | 3M/月 | 30M/月 |
| 存储（DB数据） | ~50KB/用户 | 50 MB | 500 MB | 5 GB |
| 带宽 | ~200KB/DAU | 6 GB/月 | 60 GB/月 | 600 GB/月 |

**Supabase 成本随DAU增长**：

| DAU | 适用 Tier | 月费 | 备注 |
|-----|----------|------|------|
| 0 - 1,700 | Free | $0 | 50K MAU上限 |
| 1,700 - 3,300 | Pro | $25 | 100K MAU上限 |
| 3,300+ | Pro + 超额 | $25 + 超额费 | 超出部分按量计费 |
| 10,000+ | Team | $599 | 1M MAU, 100G DB |

> **注意**：Supabase 的 MAU 计算方式为"每月至少调用一次 API 的独立用户"。离线玩家不计入 MAU。实际上 1K DAU = ~30K MAU，因此 Free Tier 可支撑到约 1.7K DAU。

## 2. 平台分成

### 2.1 Apple App Store

| 方案 | 分成比例 | 条件 |
|------|---------|------|
| 标准分成 | 30% | 年收入 > $1,000,000 |
| Small Business Program | 15% | 年收入 ≤ $1,000,000 |
| 订阅第二年+ | 15% | 订阅超过1年的用户 |

**Boba Dash 适用**：Small Business Program，15% 分成。

### 2.2 Google Play

| 方案 | 分成比例 | 条件 |
|------|---------|------|
| 标准分成 | 30% | 年收入 > $1,000,000 |
| 前 $1M 收入 | 15% | 年收入 ≤ $1,000,000 |
| 订阅连续12月+ | 15% | 订阅超过12个月的续费 |

**Boba Dash 适用**：前 $1M 收入仅 15% 分成。

### 2.3 PayPal (Web Store)

| 地区 | 费率 | 固定费 |
|------|------|--------|
| 美国 | 3.49% + $0.49 | 每笔交易 |
| 国际 | 4.99% + $0.49 | 每笔交易 |

> **策略**：Web 商店作为 iOS/Android 外的补充渠道，主要面向无法或不愿使用 App Store 的用户。由于费率更高，仅在移动端购买渠道不可用时推荐。

## 5. 盈亏平衡分析

### 5.1 收入模型

Boba Dash 采用 **5轨18 SKU** 变现模型（零广告）：

| 变现轨道 | SKU数 | 价格范围 | 预估付费率 | ARPU贡献 |
|----------|-------|----------|-----------|----------|
| Season Pass | 1 | $4.99/月 | 3% | $0.15 |
| Friend Slots 扩充 | 3 | $1.99 - $5.99 | 5% | $0.08 |
| Robot 员工 | 3 | $0.99 - $9.99 | 4% | $0.06 |
| Recipe Slots | 2 | $1.99 - $3.99 | 3% | $0.04 |
| 装饰包 | 9 | $0.99 - $4.99 | 8% | $0.12 |
| **合计** | **18** | | | **$0.45** |

### 5.2 ARPU 场景分析

```typescript

const scenarios = {

    coinPackRate: 0.04,      // 4% 买金币包
```

### 5.3 盈亏平衡 DAU

| 场景 | ARPU | 月均收入 (X DAU × ARPU) | 盈亏平衡DAU | 月利润 (1K DAU) | 月利润 (5K DAU) |
|------|------|------------------------|------------|----------------|----------------|
| **保守** | $0.30 | $0.30 × DAU | **230** DAU | $81 | $1,156 |
| **基准** | $0.50 | $0.50 × DAU | **138** DAU | $281 | $3,406 |

## 6. 成本优化策略

### 6.1 启动阶段 (0-1K DAU)

| 策略 | 节省 | 影响 |
|------|------|------|
| 使用 Supabase Free Tier | $25/月 | 需自行管理备份（pg_dump cron） |
| 使用免费音效库替代 Epidemic Sound | $15/月 | 音效质量和种类降低 |
| Apple Small Business Program 注册 | 15% vs 30% 分成 | 年收入<$1M 可申请 |
| Cursor 使用 Hobby 爱好计划 | $20 → $0/月 | 限每月2000次AI调用 |

**优化后月费**：从 $69 → **$8.25/月**（仅 Apple Developer）

### 6.2 增长阶段 (1K-10K DAU)

| 策略 | 节省 | 说明 |
|------|------|------|
| 优化 Edge Function 调用频率 | 减少超额费 | 客户端缓存 + 批处理 |
| 启用 PgBouncer | 减少连接数 | Pro Tier 包含 |
| UI 内预加载离线数据 | 减少 API 请求 | 社交数据5分钟缓存 |

### 6.3 大规模阶段 (10K+ DAU)

| 策略 | 节省 | 说明 |
|------|------|------|
| 自托管 Supabase (AWS/GCP) | 减少 SaaS 溢价 | 需要 DevOps 能力 |
| CDN 加速 Storage | 减少带宽成本 | Cloudflare Free Tier |
| 排行榜使用物化视图 | 减少查询成本 | 替代实时排序 |

## 7. 财务风险与缓解

### 7.1 最大风险：零收入

**情景**：DAU增长但付费转化率低于预期（<2%）。

**缓解**：
- 在1K DAU时评估是否继续投入
- 引入激励视频广告作为保底收入（$3-5 CPM = $0.03-0.05/DAU/月）
- 如果 5K DAU 仍无正向现金流，考虑转型或关停

### 7.2 次要风险：平台政策变化

**情景**：Apple 强制要求 Sign-in with Apple 成本或政策变化。

**缓解**：
- 已内置 Apple Sign-in（App Store 当前要求）
- 多平台策略（Web PayPal 商店作为备选）

### 7.3 工具成本增长

**情景**：Supabase / RevenueCat 涨价或调整 Free Tier。

**缓解**：
- Supabase 开源可自托管
- RevenueCat 有 Nami / Glassfy 等竞品可迁移
